- 全量 `npm run check` 仍会命中仓库已有的 JavaScript 隐式 `any` 与 Svelte 类型错误；本轮定向测试和生产构建均通过。
- `.codegraph/` 是用户已有的未跟踪目录，不纳入本次提交。
- 官方设置参考采用全页管理布局，而当前系统采用设置弹层；用户已明确本轮不调整设置框架，因此只完成字体和特效对齐。

## 已解决

- Chrome 108 浅色主题颜色、阴影和边框因不支持 `color-mix(in oklab, ...)` 而丢失的问题，已由构建期兼容回退解决并在 Chrome 108/149 实测通过。
- 聊天消息中的多行 SVG 被当作文本展示的问题，已接入现有 SVG 清理与查看组件安全渲染。
- 登录页因 Archivo 字体和官方字重被移除、控件被加重而与官方镜像存在的视觉差异，已在 Chrome 108 下完成同视口对齐。
- 全站大量文字被统一为 `font-normal` 导致的层级丢失，已按官方历史源码恢复；设置页开关、浅色输入表面和中文说明已在 Chrome 108 下验收。
- 侧栏、账户菜单、设置导航和聊天首页字号/密度偏小的问题，已按官方截图比例调整，并在 Chrome 108 的 2048×968、1366×768 视口下验收。
- 账户菜单上下分组字号不一致、设置说明过小及设置面板中文缺失的问题，已统一为 15px 菜单和 16/14/13px 设置层级，并通过全设置组件本地化测试与 Chrome 108 验收。
- 已解决：此前移除 `.data` 临时方案的决定已被用户最终决策取代；当前以通用静态资源别名实现，不包含特定下载管理器配置，并已在真实浏览器中完成 Python 实跑。
- Pyodide 准备脚本用依赖声明范围比较实际静态版本、导致每次构建重复清理下载的问题，已改为比较实际安装版本。
- 2026-08-30 上游同步后的依赖缺失已解决：联网安装补齐 `docx-preview`，8 GB Node 堆下生产构建成功。
